# Meus Gastos

App simples de controle de gastos (PWA), feito pra usar no iPhone.

- Os dados ficam salvos só no aparelho (localStorage). Nada vai pra servidor.
- Funciona sem internet depois de instalado.
- Backup em JSON e exportação em CSV pelo menu Ajustes.

**Instalar no iPhone:** abra o link no Safari → Compartilhar → Adicionar à Tela de Início.

**Ao mudar algum arquivo:** aumente a `VERSAO` no `sw.js` para os celulares pegarem a versão nova.
